# Escape Velocity Contact Clone (Contact Form & Footer Layout)

A simplified frontend recreation inspired by the contact section of the Escape Velocity template from HTML5 UP. This educational portfolio project focuses on recreating a modern contact form and footer layout using semantic HTML and CSS.

[🔗 **Live Preview**](https://karchmarek.github.io/Escape-velocity-footer-clone/)

## 🚀 Tech Stack

- **HTML5** – Semantic page structure.
- **CSS3** – Custom styling, Flexbox layouts, typography, and responsive design.
- **Normalize.css** – Consistent default styling across browsers.
- **Bootstrap Icons** – Vector icons used throughout the contact section.

---

## 💡 What I Practiced

- **Semantic HTML** – Built a structured contact section using semantic elements.
- **Forms** – Created a styled contact form with text inputs, textarea, and action buttons.
- **Flexbox Layouts** – Built a responsive two-column layout for the form and contact information.
- **Reusable Components** – Designed reusable buttons, feature blocks, and icon containers.
- **Typography & Spacing** – Recreated the visual hierarchy, spacing, and styling of the original design.

---

## 🎯 Project Goal

The goal of this project was to recreate the contact section of the Escape Velocity template using only HTML and CSS.

The project focuses on:

- Building a modern contact form.
- Creating a responsive two-column footer layout.
- Styling reusable buttons and feature cards.
- Integrating icon-based contact information.
- Writing clean, semantic, and maintainable frontend code without JavaScript frameworks.
